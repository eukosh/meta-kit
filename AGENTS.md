# meta-kit

CLI and MCP server for Instagram, Facebook Pages and Threads, built on Meta's official APIs. Planning stage: the wayfinder map on GitHub Issues charts the way to the spec.

## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues, operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
